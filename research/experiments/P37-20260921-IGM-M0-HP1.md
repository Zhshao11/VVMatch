## Question

Can the standalone IGM-M0 train from scratch on HPatches and reach a
non-catastrophic or better sequence-held-out geometry endpoint than the
OfficialSLiM architecture trained from scratch under the same HPatches data,
exposure, and evaluator?

This experiment establishes the independent base only. It does not test M1
covisibility routing, M2 geometry-feedback approximation, or M3 representation
pretraining.

## Execution Funnel

1. `S0`: recover the exact E-051 108-sequence allowlist without reading any
   metric; apply the frozen hash split; emit sequence, pair, direction, file,
   and role manifests plus zero-intersection audit.
2. `S1`: implement IGM in an independent package and baseline in a separate
   process. Freeze source/config/manifests and pass dependency, shape,
   coordinate, assignment, refinement, evaluator, random/wrong-pair, and
   identity tests.
3. `S2/S3`: same-parameterization synthetic controls, eight-pair tiny overfit,
   gradients, optimizer membership, parameter deltas, reload, and action path.
4. Resource preflight: time real train-role batches for both arms, including
   augmentation, forward/backward, optimizer, checkpoint, and evaluation. Stop
   if the credible four-trajectory forecast exceeds 48 GPU-hours.
5. Formal: run two independent seeds for each arm, exactly 20,000 steps. Long
   jobs and queued GPU work use watchdog on `zzvr`; independent trajectories
   may occupy separate idle GPUs without DDP.
6. Freeze both final checkpoints, source/config/data hashes, and endpoint
   decision before opening evaluation payloads. Then run the common paired
   evaluator and write one terminal `RESULT_CARD.md/json`.

## Required Review

Training paths and a new evaluator/data split require two focused reviews. The
first checks method semantics, independence, coordinates, labels, gradients,
and checker coverage. The second checks split leakage, sample-stream parity,
RANSAC/cap/aggregation, caching, and endpoint freeze. Review only the packet,
changed code, named high-risk functions, and automated summaries.

## Result Boundary

The prior motivating result is historical D0 `58.05/67.05/76.86` versus O0
`55.10/64.68/74.00`, but both were MegaDepth-trained and do not answer the new
matched-scratch question. This experiment can reject the exact M0 recipe if
implementation and training adequacy pass; it cannot reject independent
matching or any M1-M3 mechanism. Since HPatches was historically consumed, a
pass is retrospective internal evidence, not a pristine final benchmark.

Forbidden: SourceMux, `bl_tunnel`, MegaDepth for training, SAR, OSDataset,
heldout1200, Gate2/test/final/protected data, pretrained matcher checkpoints,
best-of-repeat metrics, post-hoc threshold/checkpoint selection, and artifact
delete/overwrite.
